# 协同事务平台

协同事务平台为需要多机构参与的业务提供统一的机构、授权、案件、证据、审批、资源预约、资金分录、消息归并、通知、定时任务和历史回放能力。项目只使用 Python 标准库与 SQLite，适合在单个 Linux 应用容器内运行。

## 城市休闲化指数复核

`civicflow.leisure` 在平台原语之上承载研究秘书处的指数复核工作：

- **按城市与统计期留痕**：人口基准（常住/城区/市域三种口径）、休闲资源、服务覆盖、空间密度、样本出处与指标权重均按 `(城市, 统计期, 指标)` 版本化保存；每次计算把所用单位、覆盖期和**分母版本**固定进计算记录。
- **报送批次幂等与冲突**：同一批次编号再次提交直接返回既有处理结果；编号相同但内容不一致时登记冲突、暂不入库也不计算。
- **调整双签**：单位换算或指标权重调整必须说明原因，经另一名成员确认后才影响待发布结果；未确认的换算会阻止计算。权重以整套维度一起调整，确认后权重之和恒为 1。
- **迟到修订的范围重算**：关账后迟到补录需显式标记 `late`，只触发受影响维度与城市的重算，未受影响维度沿用上一版计算（记录继承关系），其他城市不受影响。
- **榜单冻结与勘误**：正式发布的年度榜单不可变，发布时刻的计算被冻结；迟到修订产生的新结果通过带关联关系的勘误（关联前后两次计算）说明变化。
- **合作机构城市授权**：合作机构只能查阅和报送获授权城市的数据，榜单与追溯视图同样按授权裁剪。
- **重启续作**：催收任务进入持久化任务队列，关账状态落库，进程重启后催收、复核和关账均可继续；批次重放仍返回原结果。
- **完整追溯**：从榜单任一名次可追到当时的指标值、人口口径与版本、来源材料、覆盖期、调整理由及提出/确认双方责任人。

走完一遍复核链路（报送 → 换算双签 → 计算 → 发布 → 关账 → 迟到补录 → 勘误 → 催收）：

```bash
PYTHONPATH=src python3 -m civicflow.cli --db /tmp/leisure-demo.sqlite3 leisure-demo
```

## 目录

- `src/civicflow/`：领域服务、SQLite 持久化、权限和命令行入口。
- `tests/`：核心流程、边界条件和异常路径测试。
- `examples/`：本地演示输入。

## 配置

通过 `CIVICFLOW_DB` 指定 SQLite 文件路径；不设置时命令行使用当前目录下的 `civicflow.sqlite3`。所有时间使用带时区的 ISO 8601 字符串。

## 测试

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## 编译或构建

```bash
PYTHONPATH=src python3 -m compileall -q src
```

## 使用

初始化数据库并运行离线演示：

```bash
PYTHONPATH=src python3 -m civicflow.cli --db /tmp/civicflow-demo.sqlite3 demo
```

查看当前案件：

```bash
PYTHONPATH=src python3 -m civicflow.cli --db /tmp/civicflow-demo.sqlite3 list-cases
```
